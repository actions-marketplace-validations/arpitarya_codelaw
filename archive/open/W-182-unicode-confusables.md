## Built (2026-11-17)

- **The table:** Unicode 18.0.0's `confusables.txt` (SHA-256 `6ed3ee96…5b92`, Unicode License v3), kept to the single non-ASCII code points whose prototype is one printable ASCII character — 1,857 of 6,712 entries; the others (ASCII sources, prototypes of several characters such as `“` → `''`, `…`, ligatures, fractions) are not one character mistaken for another.
- **The rules:** `py/ambiguous-unicode-character-string`, `-docstring`, `-comment`, Ruff's word rule (ASCII beside it, or nothing but confusables), `suggest` with the ASCII character, an `allowed_confusables` option; the table is asked for only when the text has a non-ASCII character.
