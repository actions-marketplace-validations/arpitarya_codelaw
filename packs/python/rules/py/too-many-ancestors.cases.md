# py/too-many-ancestors — cases

### case: seven ancestors are not too many

```py files
# app/__init__.py
# app/base.py
class A: ...
class B(A): ...
class C(B): ...
class D(C): ...
class E(D): ...
class F(E): ...
class G(F): ...
class H(G): ...
```

```expect
(none)
```

### case: a base through a module alias and a re-export

```py files
# app/__init__.py
from .base import G
# app/base.py
class A: ...
class B(A): ...
class C(B): ...
class D(C): ...
class E(D): ...
class F(E): ...
class G(F): ...
# app/one.py
import app.base as base


class H(base.G): ...
# app/two.py
import app


class I(app.G): ...
# app/three.py
from app import G


class J(G): ...
```

```expect
(none)
```

### case: eight ancestors

```py files
# app/__init__.py
# app/base.py
class A: ...
class B(A): ...
class C(B): ...
class D(C): ...
class E(D): ...
class F(E): ...
class G(F): ...
class H(G): ...
# app/leaf.py
from app.base import H


class Leaf(H): ...
```

```expect
app/leaf.py:4:7 py/too-many-ancestors
```
