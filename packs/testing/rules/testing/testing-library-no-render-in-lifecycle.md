`render(…)` is called in the test, not in `beforeEach` or `beforeAll`.

**Why:** Rendering in a hook shares one rendered tree across tests and hides what each one renders; Testing Library cleans up after every test, so a `beforeAll` render is gone by the second.

message: "Render in the test, not in a hook"

## How to fix

1. Move the `render` call into each test, or into a `setup()` helper the tests call.

## Examples

### JavaScript

#### Don't

```js
beforeEach(() => {
  render(<App />);
});
```

#### Do

```js
test("t", () => {
  render(<App />);
});
```

### JSX

#### Don't

```jsx
beforeEach(() => {
  render(<App />);
});
```

#### Do

```jsx
test("t", () => {
  render(<App />);
});
```

### TSX

#### Don't

```tsx
beforeEach(() => {
  render(<App />);
});
```

#### Do

```tsx
test("t", () => {
  render(<App />);
});
```
