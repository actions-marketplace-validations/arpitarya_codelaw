`fireEvent.<event>(…)` is synchronous and is not awaited. The suggested edit drops the `await`.

**Why:** Awaiting a synchronous call suggests the event is asynchronous and hides where real waiting is needed.

## Examples

### JavaScript

#### Don't

```js
test("clicks", async () => {
  await fireEvent.click(button);
});
```

#### Do

```js
test("clicks", async () => {
  fireEvent.click(button);
});
```
