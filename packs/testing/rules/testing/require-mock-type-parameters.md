`vi.fn()` is given the type of the function it stands for: `vi.fn<(id: string) => User>()`. Opt-in.

**Why:** Untyped, a mock accepts any call and returns `any`, so a test can drift from the code it mocks and still compile.

## How to fix

1. Add the function's type: `vi.fn<typeof realFn>()` or `vi.fn<(id: string) => User>()`.

## Examples

### TypeScript

#### Don't

```ts
const get = vi.fn();
```

#### Do

```ts
const get = vi.fn<(id: string) => User>();
```

### TSX

#### Don't

```tsx
const get = vi.fn();
```

#### Do

```tsx
const get = vi.fn<(id: string) => User>();
```
