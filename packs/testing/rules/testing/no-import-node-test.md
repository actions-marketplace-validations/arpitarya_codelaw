A test file imports its test functions from `vitest`, not from Node's built-in `node:test`.

**Why:** `node:test`'s `test` and `describe` register with Node's runner, not Vitest's, so those tests never run under Vitest.

```codelaw

  expect-call:
    kind: call_expression
    has:
      field: function
      any:
        - { kind: identifier, regex: '^expect$' }
        - kind: member_expression

            - has: { field: object, kind: identifier, regex: '^expect$' }

    any:
      - matches: expect-call
      - kind: member_expression
        has:
          field: object
          any:
            - matches: expect-call
            - { kind: member_expression, has: { field: object, matches: expect-call } }
  matcher-call:
    kind: call_expression
    has:
      field: function
      kind: member_expression

  test-name:

    kind: call_expression

        - matches: test-name
        - kind: call_expression
          has:
            field: function

    kind: call_expression

  kind: string

  inside: { kind: import_statement, field: source }
message: "Import from `vitest`, not `node:test`"
fix: '"vitest"'
```

## Examples

### JavaScript

#### Don't

```js
import { test } from "node:test";
```

#### Do

```js
import { test } from "vitest";
```

#### Do
