A `jest.mock(path, factory)` call names the module's type: `jest.mock<typeof import("./api")>("./api", () => …)`, so the factory is checked against the real module.

**Why:** Without the type argument the factory can return anything, and a mock that drifts from the module still compiles.

## Examples

### TypeScript

#### Don't

```ts
jest.mock("./api", () => ({ get: jest.fn() }));
```

#### Do

```ts
jest.mock<typeof import("./api")>("./api", () => ({ get: jest.fn() }));
```

### TSX

#### Don't

```tsx
jest.mock("./api", () => ({ get: jest.fn() }));
```

#### Do

```tsx
jest.mock<typeof import("./api")>("./api", () => ({ get: jest.fn() }));
```
