`vi.mock` is given the module as `import("./path")`, not as a string.

**Why:** With `import()` the editor follows the path, a rename updates it, and the factory is typed against the module.

## Examples

### JavaScript

#### Don't

```js
vi.mock("./api", () => ({ get: vi.fn() }));
```

#### Do

```js
vi.mock(import("./api"), () => ({ get: vi.fn() }));
```

### JSX

#### Don't

```jsx
vi.mock("./api", () => ({ get: vi.fn() }));
```

#### Do

```jsx

```
