A mocked value is typed with `vi.mocked(fn)`, not asserted with `fn as Mock`, `MockedFunction<…>`, `MockedClass<…>`, `MockedObject<…>` or `Mocked<…>` (Vitest's types, with or without a `vi.` prefix).

**Why:** `vi.mocked` keeps the function's own parameter and return types; an `as` assertion throws them away.

## Examples

### TypeScript

#### Don't

```ts
test("calls", () => {
  (fetchUser as Mock).mockResolvedValue(user);
});
```

#### Do

```ts
test("calls", () => {
  (vi.mocked(fetchUser)).mockResolvedValue(user);
});
```

### TSX

#### Don't

```tsx
test("calls", () => {
  (fetchUser as Mock).mockResolvedValue(user);
});
```

#### Do

```tsx
test("calls", () => {
  (vi.mocked(fetchUser)).mockResolvedValue(user);
});
```
