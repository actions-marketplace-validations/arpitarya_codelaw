`test.todo(…)` and `it.todo(…)` are reported, so placeholders are seen. Opt-in.

**Why:** A todo is a test nobody wrote; reporting it keeps the list visible.

## How to fix

1. Write the test, or delete the placeholder.

## Examples

### JavaScript

#### Don't

```js
test.todo("handles errors");
```

#### Do

```js
test("handles errors", () => {
  expect(() => run(null)).toThrow("input");
});
```
