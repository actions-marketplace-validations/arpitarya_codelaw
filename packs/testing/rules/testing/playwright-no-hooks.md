A test file has no `beforeAll`, `beforeEach`, `afterEach` or `afterAll`: each test sets up what it needs. Opt-in; a style some teams choose. The Playwright Test counterpart of `testing/no-hooks`, for `test`, `test.describe` and `test.beforeEach`.

**Why:** Setup in hooks is shared state that each test reads implicitly; a helper the test calls makes it explicit.

```codelaw
message: "Call a setup helper from the test instead of a hook"
```

## How to fix

1. Write a function that returns what the hook prepared.
2. Call it at the start of each test that needs it, and delete the hook.

## Examples

### JavaScript

#### Don't

```js
beforeEach(() => {
  db.reset();
});
```

#### Do

```js
test("a", () => {
  const db = freshDb();
});
```
