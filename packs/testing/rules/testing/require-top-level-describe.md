Every test and hook in a file is inside a `describe` block. Opt-in.

**Why:** A top-level `describe` names the unit under test in every report line, and scopes the file's hooks.

```codelaw

message: "Put this inside a `describe` block"
```

## How to fix

1. Wrap the file's tests and hooks in `describe("<the unit>", () => { … })`.

## Examples

### JavaScript

#### Don't

```js
test("adds", () => {});
```

#### Do

```js
describe("add", () => {
  test("adds", () => {});
});
```
