A test or block calls `test.slow()` once; the fix removes a repeated call.

**Why:** `test.slow()` triples the timeout once; a second call does nothing and suggests otherwise.

## Examples

### JavaScript

#### Don't

```js
test("big", async () => {
  test.slow();
  test.slow();
});
```

#### Do

```js
test("big", async () => {
  test.slow();
});
```
